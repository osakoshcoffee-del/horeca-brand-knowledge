# Метрики и дашборд: как считать маркетинг напиточного бренда

Минимальный набор цифр, который нужен еженедельно, ежемесячно и ежеквартально.

## Северная звезда

**Повторные покупки (B2C) и активные точки (B2B)**. Всё остальное - вспомогательные метрики.

## Воронка B2C: что считать

| Этап | Метрика | Норма/ориентир |
|---|---|---|
| Охват | Просмотры Reels, охват постов | Рост м/м |
| Вовлечение | Сохранения, пересылки, ER | Сохранения растут быстрее лайков |
| Переход | Клики в профиль, переходы по ссылке | 1-3% от охвата |
| Лид | Подписка на канал, сообщение в директ, добавление в корзину | - |
| Покупка | Заказы, конверсия сайта/карточки | 1-3% для D2C сайта |
| Возврат | Повторная покупка за 60 дней | 25-40% для напитков |
| Экономика | CAC, LTV, маржа | LTV/CAC > 3 |

## Воронка B2B: что считать

| Этап | Метрика |
|---|---|
| Касания | Семплы отправлено, встречи, посевы |
| Интерес | Ответившие шефы, запросы прайса |
| Тест | Точки в тестовой поставке |
| Контракт | Новые активные точки |
| Удержание | Повторный заказ за 60 дней (норма 70%+) |
| Расширение | Средний чек поставки, точек на одного клиента |

## Канальная матрица (ежемесячно)

Таблица: канал -> затраты -> лиды -> продажи -> стоимость лида -> стоимость клиента -> вывод (масштабировать/держать/убить).

Каналы: Instagram (органика), Telegram посевы, Telegram Ads, выставки/ивенты, маркетплейсы (внутренняя реклама), email, сарафан.

## Контент-аналитика (еженедельно)

- Топ-3 и анти-топ-3 поста/ролика за неделю по: удержанию, сохранениям, пересылкам, заявкам.
- Гипотеза почему сработало / не сработало (одна фраза на контент).
- Решение: что повторяем, что закрываем.

## Дашборд (один экран)

1. Выручка за месяц: B2C / B2B.
2. Новые клиенты и повторные покупки.
3. Активные точки и динамика.
4. Лучший канал по стоимости клиента.
5. Топ-контент недели.
6. План на месяц vs факт (в процентах).

## Правила чтения цифр

1. Смотрим тренды, а не точки. Один плохой месяц - шум, три - сигнал.
2. Не сравниваем каналы по лайкам: сравниваем по стоимости клиента и LTV.
3. Любая метрика без решения бесполезна. Формат: цифра -> вывод -> действие.
4. В HoReCa цикл сделки длинный: метрики B2B смотрим по кварталам, контентные - по неделям.
